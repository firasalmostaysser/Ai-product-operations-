## The 90-Day Plan (Overview)

### Phase 1: AI Tools Mastery (Days 1-14)
Master the tools that make you 10x productive. Cursor AI, Claude (Code + Chat), Codex, v0, Bolt.new, Lovable, Replit Agent. You already use Cursor -- now go deep.

### Phase 2: AI Agents & MCP (Days 15-28)
Understand what AI agents actually are, how they work, what MCP (Model Context Protocol) is, how to build agents, and how to deploy them. This is the knowledge gap that stops most people.

### Phase 3: AI Product Operations (Days 29-42)
Learn the frameworks, metrics, and workflows that AI Product Ops roles actually need. Understand how companies run AI products at scale.

### Phase 4: AI Automation Builders (Days 43-56)
Master n8n, Make (Integromat), Zapier, and custom automation. Build real workflows that solve real business problems. This is where you start making money.

### Phase 5: Portfolio & Income (Days 57-75)
Build 5 portfolio projects that prove your skills. Start freelancing. Ship tools that people pay for.

### Phase 6: GTM & Market Strategy (Days 76-90)
Learn go-to-market strategy for AI products. Understand positioning, competitive analysis, and market intelligence.
