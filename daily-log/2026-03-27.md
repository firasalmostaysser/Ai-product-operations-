## 📚 What I Learned

- **AI Agent**: A program that uses an LLM to reason and use tools to take actions in a loop until a goal is completed. Not magic — just a loop of "think → act → observe."
- **MCP (Model Context Protocol)**: A standard by Anthropic that lets AI tools (Claude, Cursor) talk to external services (databases, files, APIs) in a consistent way. Like USB-C but for AI + tools.
- **RAG (Retrieval-Augmented Generation)**: Give an AI a "search engine" over your documents so it can answer questions using your real data instead of just training data.
- **n8n**: Open-source visual automation platform. Like Zapier but with code capabilities, AI nodes, and self-hosting. This is my primary automation tool.
- **Tool Calling**: The mechanism by which an AI like Claude can request to run a function (like "search the web" or "read a file"). The AI doesn't run the function — it ASKS, and your code runs it.
