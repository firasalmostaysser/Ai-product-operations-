# Daily Learning Log

## Why You're Doing This

The daily log serves three purposes:

1. **Learning acceleration** — writing forces you to consolidate what you learned
2. **Portfolio signal** — 90 days of consistent commits is visible proof of work
3. **Accountability** — it's hard to skip a day when you have a streak going

## The Template

Every day, create a new file named `YYYY-MM-DD.md` and fill in the template below.
It should take 5–10 minutes maximum.

```markdown
# Daily Log — YYYY-MM-DD

## ⚡ Today's Focus
One sentence: what was the main thing you worked on?

## 📚 What I Learned
- [Concept 1]: one-sentence explanation in your own words
- [Concept 2]: one-sentence explanation in your own words
(2-5 items)

## 🔨 What I Built / Practiced
- [Thing you built or worked on]: one sentence about it
(1-3 items)

## 🆕 New Tool / Resource Discovered
- Tool/resource name: why it's interesting

## 🗣️ English Practice
- What I practiced: (reading, writing, speaking, recording, etc.)
- One thing I noticed: (grammar, pronunciation, vocabulary, etc.)

## 🚧 Blockers / What I Got Stuck On
- [Problem]: how I tried to solve it / plan to solve it tomorrow

## 💡 Tomorrow's Priority
One clear task for tomorrow.

## 📊 Streak
Day X of 90
```

## Tips

- Log in English — this is also English practice
- Be honest about blockers. They're as valuable as wins.
- It doesn't have to be long. 5 lines is fine.
- If you miss a day, log it the next day with "Missed yesterday, here's a catch-up"
- The streak itself is the achievement. Protect it.
