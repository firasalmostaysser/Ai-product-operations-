# 180-Day Roadmap (AI Product Ops / GTM / Automation)

This is your execution map.  
Do not overthink it. Follow it.

## Phase 1 (Days 1-30): Foundations + Fast Wins

### Goals

- Build clarity on role positioning and target job titles
- Create first proof-of-work project
- Set up daily learning + update system

### Skills to build

- Automation basics (APIs, webhooks, workflow logic)
- AI prompting for operations tasks
- Basic agent architecture concepts
- Product and GTM metrics essentials

### Deliverables

1. Portfolio Project #1 live demo + README
2. LinkedIn rewritten using new positioning
3. CV version for AI Product Ops and AI Automation roles
4. 20 targeted job applications
5. 10 networking conversations started

---

## Phase 2 (Days 31-60): Intermediate Build + Public Presence

### Goals

- Build second project with stronger business value
- Publish weekly content proving your expertise
- Improve interview performance and spoken communication

### Skills to build

- Multi-step automation design
- Prompt chaining and error handling
- Dashboarding and operational KPIs
- Discovery calls and consultative communication

### Deliverables

1. Portfolio Project #2 (Ops + GTM focus)
2. 4 LinkedIn posts (case-study style)
3. 30 additional applications (customized)
4. 10 more networking messages
5. 5 mock interviews completed

---

## Phase 3 (Days 61-90): Advanced Proof + Job Conversion

### Goals

- Build third flagship project (agent + MCP concept)
- Convert interviews into offers
- Start earning from freelance micro-offers

### Skills to build

- Agent architecture and tool-calling patterns
- MCP basics and integration mindset
- Production quality: observability, fallback logic, reliability
- Advanced storytelling in interviews

### Deliverables

1. Portfolio Project #3 flagship
2. 50 additional high-quality applications
3. 2-3 small paid gigs (freelance/consulting)
4. Personal website/Notion portfolio with all 3 projects
5. Interview answer bank finalized

---

## Phase 4 (Days 91-180): Scale and Specialize

### Goals

- Become top-tier candidate in your niche
- Build compounding reputation and opportunities
- Create recurring revenue from AI automation services

### Tracks (choose one primary + one secondary)

1. **Primary A**: AI Product Operations Specialist  
2. **Primary B**: AI GTM / RevOps Specialist  
3. **Secondary**: AI Agent Builder for SMB workflows

### Deliverables

- 1 advanced case study/month
- 2 open-source templates/month
- 1 workshop or tutorial/month
- 4 high-value applications/month (quality > quantity)

---

## Weekly Scorecard (Non-Negotiable)

Track these every Sunday:

- Learning hours completed
- Number of shipped artifacts
- Number of job applications
- Number of networking conversations
- Number of interview rounds
- Revenue earned (if any)

If score drops for 2 weeks, simplify and return to daily basics.
