# 03 - Daily System (Your Career Operating Routine)

This is your default day plan.
Do this even when motivation is low.

## Daily Structure (5 blocks)

### Block 1 (60-90 min): Learn with purpose

- Read one focused topic from your roadmap (not random videos)
- Take 10 bullet notes in your own words
- Write one "how this helps a business" sentence

### Block 2 (90-120 min): Build

- Work on current portfolio project
- Target one concrete output:
  - one workflow,
  - one feature,
  - one bug fix,
  - one dashboard section

### Block 3 (30-45 min): Document and publish signal

- Update README / case study notes
- Post one short insight on LinkedIn/X:
  - what problem you solved,
  - how you solved it,
  - what metric improved

### Block 4 (45-60 min): Job pipeline execution

- Send 3-5 tailored applications
- Send 1-2 targeted networking messages
- Update `data/job_pipeline.csv`

### Block 5 (30 min): Communication training

- Record yourself answering one interview question in English
- Re-listen and improve clarity (slower pace, simpler structure)
- Practice one STAR story

---

## Minimum Viable Day (if you have low energy)

If you cannot do full routine, do this:

1. 30 min learning
2. 45 min build
3. 1 application
4. 1 networking message

Never let two zero-days happen in a row.

---

## Weekly Rhythm

### Monday
- Plan top 3 outcomes for the week

### Tuesday to Thursday
- Deep build + applications

### Friday
- Publish progress summary post
- Send follow-ups

### Saturday
- Mock interview + English speaking practice

### Sunday
- Review scoreboard and plan next week

---

## Daily Output Rule

Each day must leave at least one artifact:

- code commit
- case study note
- post
- application
- outreach message

Output is how opportunities find you.
