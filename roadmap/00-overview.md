## The 6-Phase Plan

### Phase 0: Foundation (Week 1–2) — Install Everything, Understand Everything

This is where you stop feeling lost and start feeling equipped.

**What you do:**
- Install and activate: Cursor IDE, Claude API, n8n (local), Windsurf, GitHub Copilot
- Understand what an AI agent is (a program that uses LLMs to reason + take actions)
- Understand what MCP is (Model Context Protocol — lets Claude/GPT talk to your tools)
- Understand what n8n is (visual workflow automation with 400+ integrations)
- Read 5 articles on AI Product Operations job descriptions
- Watch 3 YouTube videos on AI agent architecture
- Build your first "hello world" with Claude API (just call the API and get a response)

**End state:** You feel oriented. You know the vocabulary. You have the tools installed.

---

### Phase 1: First Builds (Week 3–6) — Make Real Things That Work

This is where you stop watching and start building.

**What you build:**
1. **CV Tailoring Agent** — paste a job description, agent rewrites your CV sections
2. **Job Alert Automation** — n8n workflow that monitors LinkedIn/job sites and emails you matching roles
3. **Outreach Personalizer** — n8n + Claude: given a company URL, auto-drafts a personalized cold email
4. **Meeting Summary Bot** — feeds a transcript, outputs structured meeting notes + action items

**What you learn:**
- Prompt engineering (how to write good system prompts)
- n8n basics (triggers, actions, HTTP nodes, AI nodes)
- Claude API (messages API, system prompts, tool use)
- GitHub basics (commit, push, README)

**End state:** You have 4 working projects on GitHub with READMEs. You start posting them on LinkedIn.

---

### Phase 2: Depth (Week 7–12) — Become Genuinely Good

This is where you go from "I can build things" to "I understand how this all works."

**What you learn:**
- **AI Agents architecture** — ReAct pattern, tool calling, memory, multi-step reasoning
- **MCP (Model Context Protocol)** — connect Claude to databases, APIs, file systems
- **LangChain / LangGraph** — build agents with memory, loops, parallel tool calls
- **RAG (Retrieval-Augmented Generation)** — give your agents a "knowledge base" to search
- **Vector databases** — Supabase pgvector, Pinecone (store embeddings for semantic search)
- **Prompt engineering mastery** — chain-of-thought, few-shot, structured outputs
- **Product metrics and analytics** — what to measure in AI products (latency, quality, cost)

**What you build:**
5. **Personal Knowledge Assistant** — RAG system over your notes/documents
6. **AI Product Ops Dashboard** — metrics tracker for an AI product (mock data is fine)
7. **Customer Onboarding Agent** — simulates onboarding a new user using agent + tools
8. **Multi-step Research Agent** — given a company name, researches and produces a briefing doc

**End state:** You can explain what a vector database is, build a RAG pipeline from scratch, and have 8 portfolio projects.

---

### Phase 3: Specialization (Month 4) — Pick Your Primary Market

By now you'll know what you enjoy most. Pick ONE primary position to double down on:

**Option A: AI Product Operations** → Apply aggressively to remote roles. Your sweet spot.
**Option B: AI Automation Freelancer** → Start on Upwork, Toptal, referrals. Fastest cash.
**Option C: GTM AI Engineer** → Target early-stage SaaS. Join their Slack, offer a free audit.
**Option D: AI Agent Developer** → Build a SaaS tool. Takes longer but highest ceiling.

**For Firas specifically:** Target AI Product Operations (jobs) + AI Automation Freelance (income now) simultaneously.

### Phase 5: Scale (Month 5–6) — Get Paid Consistently

**Jobs track:**

**Freelance track:**

- Clients 4–10: charge $500–$1,500

**End state:** You have either a remote job offer or $1,000+/month in freelance income.

## Why Tunisia Is Not a Disadvantage

Stop thinking of Tunisia as a limitation. Here's the reality:

1. **Remote-first companies** don't care where you are — they care if you can do the work
2. **EMEA timezone** (UTC+1) = perfect for UK, France, Germany, Nordic companies
3. **Trilingual** = you can serve MENA clients (Arabic), Francophone Africa (French), and global (English)
4. **Cost arbitrage** = you can charge less than Western developers and still earn very well relative to local costs — this makes you competitive for early-stage startups
5. **Underserved market** = there's almost nobody in Tunisia doing serious AI automation work. You can be the first.

Companies like **Storyteller** explicitly hire in Tunisia. **Supabase** targets EMEA. **Remote.com**, **GitLab**, **Automattic**, **Notion**, **Linear** — all hire globally.
