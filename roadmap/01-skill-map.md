# Skill Map: Every Skill You Need, Ranked by Priority

## How to Use This

Each skill has:
- **Priority**: P0 (learn this week), P1 (learn this month), P2 (learn in 2-3 months), P3 (nice to have)
- **Your starting level**: 0 (no experience) to 5 (expert)
- **Target level**: What you need to reach to be hireable/billable
- **Best resource**: Where to learn it

## 30-Day Learning Sprint Plan

### Week 1 (Days 1–7): AI Foundations + Tools Setup
- Day 1: Install Cursor, Claude API, n8n local. Watch Karpathy's Intro to LLMs.
- Day 2: Read Anthropic prompt engineering guide end-to-end. Write 20 prompts.
- Day 3: Call Claude API from Node.js. Make it respond to different system prompts.
- Day 4: Build your first n8n workflow (webhook → Claude → email).
- Day 5: Learn n8n HTTP nodes. Connect n8n to a free API (weather, news).
- Day 6: Build n8n + Claude: paste a job description, get CV tailoring suggestions.
- Day 7: Commit everything to GitHub. Write a LinkedIn post about what you built.

### Week 2 (Days 8–14): Agents + MCP
- Day 8: Read the agents guide (`/courses/ai-agents-and-mcp.md`).
- Day 9: Build a simple tool-calling agent (Claude + 2 tools: web search + calculator).
- Day 10: Install and configure an MCP server (filesystem MCP).
- Day 11: Connect Claude Desktop to your MCP server. Ask it to read files.
- Day 12: Build Project #2: AI-powered meeting notes agent.
- Day 13: Add memory to an agent (store + retrieve context).
- Day 14: Update GitHub. Write a second LinkedIn post.

### Week 3 (Days 15–21): RAG + Vector Search
- Day 15: Read the embeddings explainer. Call OpenAI/Claude embeddings API.
- Day 16: Set up Supabase pgvector. Store your first embeddings.
- Day 17: Build a basic RAG system: feed it your CV, ask questions about it.
- Day 18: Improve chunking strategy. Compare results.
- Day 19: Build Project #3: Personal knowledge assistant (RAG over your notes).
- Day 20: Test and improve. Add a simple front-end (even just HTML + fetch).
- Day 21: Push to GitHub. Third LinkedIn post.

### Week 4 (Days 22–30): Portfolio + First Client Outreach
- Day 22: Polish your 3 projects. Add proper READMEs.
- Day 23: Build Project #4: Outreach personalizer (company URL → personalized cold email).
- Day 24: Complete the project. Deploy somewhere (Vercel, Railway, or keep local).
- Day 25: Update your LinkedIn profile with all 4 projects.
- Day 26: Write a tutorial about one of your projects (Dev.to or LinkedIn article).
- Day 27: Research 10 potential freelance clients in your network.
- Day 28: Send 5 personalized outreach messages.
- Day 29: Apply to 3 AI Product Operations jobs.
- Day 30: Review your progress. Update this skill map with new levels.
